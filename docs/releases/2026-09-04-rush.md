# Team-order Rush release

Based on the verified production commit b37eae60281893a9eb3417b51c9cbf19d6843515.
This release deliberately excludes the separate audit-reliability branch and
its database migrations. No database schema changes are required.

- Full team orders can select Standard or Rush before submission or invoicing.
- Rush costs $100 for 1–49 billable pieces and $150 for 50+; shipping is included.
- Team-store purchases have no Rush selector or fee; stale Rush requests are rejected.
- Paid, invoiced, submitted, quoted, Priority, and staff-arranged timelines require staff review.
- The service write checks the current timestamp and lock fields atomically.
- Submission rejects a previously reviewed price or service and guards the service at write time.
- Changing speed reloads the page; saved roster entries are retained. The UI warns to finish unsaved entries first.

Verification: seven focused tests execute the real service SQL with an isolated
in-memory PostgreSQL engine and the actual routes/invoicing with mocked external
services. Covers 16-jersey selection, 49/50-piece thresholds, mixed items, stale
submissions, lock races, shipping-included invoices, and store separation.
TypeScript and targeted new-code lint passed. Existing unrelated lint issues
are not part of this release. No real customer orders or payments were created.

Deployment verification and URL are recorded in the task conversation.
